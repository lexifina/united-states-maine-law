§731. Tie defined
There is a tie vote when 2 or more persons receive an equal number of votes, which number would entitle each one to nomination or election, except for the tie. There is a tie vote in a referendum, when a question receives an equal number of affirmative and negative votes. [PL 1985, c. 161, §6 (NEW).]
