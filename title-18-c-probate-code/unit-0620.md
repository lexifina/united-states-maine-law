§9-105. Rights of adopted persons
Except as otherwise provided by law, an adopted person has all the same rights, including inheritance rights, that a child born to the adoptive parents would have. An adoptee also retains the right to inherit from the adoptee's former parents if the adoption decree so provides, as specified in section 2‑117. [PL 2017, c. 402, Pt. A, §2 (NEW); PL 2019, c. 417, Pt. B, §14 (AFF).]
