§1-109. Transfer for value
Any recorded instrument described in this Code on which the register of deeds notes by an appropriate stamp "Maine Real Estate Transfer Tax Paid" is prima facie evidence that the transfer was made for value. [PL 2017, c. 402, Pt. A, §2 (NEW); PL 2019, c. 417, Pt. B, §14 (AFF).]
