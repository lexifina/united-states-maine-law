§5-622. Exclusive basis
This subpart provides the exclusive jurisdictional basis for a court of this State to appoint a guardian or issue a protective order for an adult. [PL 2017, c. 402, Pt. A, §2 (NEW); PL 2019, c. 417, Pt. B, §14 (AFF).]
