§2-908. Disclaimer of interest by trustee
If a trustee disclaims an interest in property that otherwise would have become trust property, the interest does not become trust property. [PL 2017, c. 402, Pt. A, §2 (NEW); PL 2019, c. 417, Pt. B, §14 (AFF).]
