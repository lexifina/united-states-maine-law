§1033. Uniform location agreement
Each slot machine or table game is subject to a uniform location agreement between the slot machine distributor or table game distributor and the slot machine operator or casino operator. A copy of the agreement must be submitted to the board for approval. The uniform location agreement is the complete and sole agreement between the slot machine operator or casino operator and the slot machine distributor or table game distributor regarding slot machines and table games. No other agreement between the slot machine operator or casino operator and the slot machine distributor or table game distributor is legally binding. [IB 2009, c. 2, §41 (AMD).]
