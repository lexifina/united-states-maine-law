§7755. MaineCare program not affected
This chapter does not apply to the MaineCare program as a payor when the MaineCare program provides reimbursement for covered outpatient drugs as defined in 42 United States Code, Section 1396r-8(k)(2). [PL 2025, c. 388, Pt. P, §5 (NEW).]
